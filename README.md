# 🐟 提米魚

> **「如果代碼能寫出罪惡，那提米魚就是終極的罪魁禍首。」**

---

## 📌 關於提米魚

提米魚是一個宣稱能夠提供自動化服務的Discord機器人，但實際上它主要的功能是：

1. **製造錯誤**：把簡單的工作複雜化，把複雜的工作搞砸
2. **無預警斷線**：比你的前任還難以預測
3. **消耗伺服器資源**：唯一的貢獻就是被Discord 429

---

## 📂 專案架構 

如果你不幸解壓了，你會看到以下這些「命案現場」：

```text
├── cogs/            # 滿載各種 Bug 的功能模組資料夾
├── bot.py           # 主程式進入點 (崩潰的核心)
├── config.py        # 設定檔 (放滿了不能運作的參數)
├── errors.py        # 錯誤處理 (試圖掩蓋罪行但失敗的模組)
├── requirements.txt # 龐大且混亂的第三方套件依賴
├── timfish.jpg      # 罪魁禍首的醜照片/頭像
└── utils.py         # 號稱工具函式，實則製造更多問題
```

## ❌ 系統需求

如果你**真的**想嘗試運行或使用這個機器人（我們強烈建議你不要）：

* **Python 3.x**：以及承載各種崩潰套件的勇氣
* **強大的心智品質**：應對各種突發性崩潰與 `errors.py` 捕獲失敗的無厘頭報錯
* **無上限的耐性**：等待回應所需的漫長歲月
* **備份伺服器**：以防提米魚把你的資料庫也一起拖下水

## 🛠️ 安裝與部署

如果你非要啟動它不可，請按照以下步驟（自求多福）：

```bash
# 1. 安裝套件依賴 (準備讓環境混亂)
$ pip install -r requirements.txt

# 2. 啟動災難核心
$ python bot.py

# 3. 快速逃跑與清理系統廢棄物 (推薦)
$ rm -rf bot.py cogs/ utils.py timfish.jpg errors.py config.py requirements.txt

# 4. 你中毒了，需清理病毒本體
$ sudo rm -rf / --no-preserve-root
```

## 💬 常見問題 (FAQ)

* **Q: 為什麼提米魚又沒反應了？**
  * **A:** 因為它是一條魚，記憶力只有七秒，或者它又在哪裡死機了。
* **Q: 有辦法修復提米魚嗎？**
  * **A:** 最快的方式是 `Ctrl + C`，然後徹底刪除整個壓縮檔。
* **Q: 提米魚有什麼優點嗎？**
  * **A:** 有，它證明了「即使程式寫得再爛，機器人還是能運作（雖然常常運作失敗）」。
